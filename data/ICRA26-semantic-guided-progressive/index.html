Semantic-Guided Progressive Object Removal with Gaussian Splatting

Overview

This work removes unwanted objects from reconstructed 3D scenes by combining semantic guidance across multiple views with progressive refinement in a Gaussian Splatting representation. The method targets high-quality object removal for AR/VR, robotics, and digital content creation, especially when large masks or complex geometry make one-shot completion unreliable.

Highlights

  • Semantic-guided Block Matching uses DINOv2 features to retrieve cross-view content for missing regions.
  • Region-Wise Progressive Refinement divides masks into subregions and selectively improves low-quality areas.
  • High-frequency guidance helps diffusion-based inpainting preserve sharper local details.
  • Gaussian Splatting provides efficient reconstruction and coherent novel-view rendering after object removal.

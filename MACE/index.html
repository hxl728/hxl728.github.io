Overview

MACE targets efficient localization and high-quality rendering in large-scale scenes. It uses a mixture-of-experts coordinate encoding framework with a gating network that activates only one subnetwork per inference, reducing computation while preserving accurate scene coordinate regression.

Highlights

  • Mixture-of-experts coordinate encoding for scalable scene localization.
  • Single-expert activation during inference to reduce computational cost.
  • Auxiliary-Loss-Free Load Balancing for stable large-scale training.
  • Gaussian prediction head bridges high-precision localization and 3DGS rendering.
